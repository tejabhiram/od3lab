# OD3 Lab website

Static site for the Ocular Drug Delivery and Discovery (OD3) Lab, University of Illinois Chicago. Hosted on GitHub Pages.

- Publications and news live in `data/content.js`. Add an entry to the top of `OD3.pubs` or `OD3.news` to update the site.
- Photos are in `img/`. Portraits are 640 x 800 px (4:5).
- Header and footer are generated by `assets/site.js`.
